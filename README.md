# Notice: I do NOT condone the use of AI in any production-level code, this is for helping me in my hobbies

These scripts are provided for transparency and so that no one else has to generate them. 

Mainly as a crutch so I don't have to worry about Blender's weirdness as much during the time I do art (one script makes it so flat colors render correctly in sRGB space since I can't find the setting anymore!)

Includes helpers for doing quick text manipulation (such as sorting), lower level changes to polygons in blender so I can change UV maps and cameras, and remapping keyboard keys for playing games when the joints in my hands flare up
